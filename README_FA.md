# اپلیکیشن KJONE

این پروژه یک پوسته اندرویدی WebView برای نمایش زنده فروشگاه https://kjone.ir است. تغییرات سایت پس از بارگذاری/تازه‌سازی در اپ نیز نمایش داده می‌شود؛ محتوا به‌صورت جداگانه داخل APK ذخیره نمی‌شود.

## ساخت خودکار APK با GitHub
1. فایل ZIP را در مخزن GitHub با گزینه **Add file → Upload files** آپلود و Commit کنید.
2. وارد زبانه **Actions** شوید.
3. گردش‌کار **Build KJONE APK** را انتخاب و در صورت نیاز **Run workflow** را بزنید.
4. پس از موفقیت، در صفحه اجرای workflow به بخش **Artifacts** بروید و `KJONE-debug-APK` را دانلود کنید.
5. ZIP آرتیفکت را باز کنید؛ فایل `app-debug.apk` داخل آن است.

حداقل نسخه Android در این پروژه API 21 (Android 5.0) تنظیم شده است. نصب و عملکرد درگاه‌ها باید روی دستگاه‌های واقعی آزمایش شود؛ تضمین سازگاری با همه گوشی‌ها ممکن نیست.
